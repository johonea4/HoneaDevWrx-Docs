# HoneaDevWrx Official Documentation & Legal Portal

Static **GitHub Pages** site hosting official user documentation, privacy policies, terms of use, and support resources for applications published by **HoneaDevWrx** (`honeadevwrx@outlook.com`, Thompson's Station, TN, US).

## Live URLs (Once GitHub Pages Is Enabled on `main` / `/ (root)`)
- **Documentation Hub:** `https://johonea4.github.io/HoneaDevWrx-Docs/`
- **Root Privacy Policy:** `https://johonea4.github.io/HoneaDevWrx-Docs/privacy-policy.html`
- **CraftLedger User Guide:** `https://johonea4.github.io/HoneaDevWrx-Docs/craftledger/`
- **CraftLedger Privacy Policy (Google Play & Microsoft Store):** `https://johonea4.github.io/HoneaDevWrx-Docs/craftledger/privacy-policy.html`
- **CraftLedger Support & FAQ:** `https://johonea4.github.io/HoneaDevWrx-Docs/craftledger/support.html`
- **CraftLedger Terms of Use:** `https://johonea4.github.io/HoneaDevWrx-Docs/craftledger/terms.html`

## Repository Structure
- `index.html` — HoneaDevWrx product & legal hub
- `privacy-policy.html` — General HoneaDevWrx privacy policy & CraftLedger coverage
- `assets/css/styles.css` — Static site stylesheet
- `assets/images/` — Brand icons & feature graphics
- `craftledger/` — CraftLedger documentation, store-compliant privacy policy, support, and terms (plus Markdown mirrors `PRIVACY_POLICY.md` and `USER_GUIDE.md`)

## Publishing to GitHub (`johonea4/HoneaDevWrx-Docs`)
```powershell
git push -u origin main
```
Then on GitHub open **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
